# covers/ - the album cover pictures

Put one picture per volume here. Square pictures look best (about 1000 x 1000
pixels), as `.jpg`, under about 500 KB each.

The name must match the `cover` line of that volume in `tracks.js`, for example
`covers/vol-v.jpg`. Keep names lower case with dashes and no spaces.

If a cover is missing or misnamed, nothing breaks: the jukebox draws a plain
paper sleeve with the volume's colour and title instead. So you can add songs
first and covers later.

The covers are shown as worn paper record sleeves. The jukebox adds the
ring-wear and a little price sticker around the edge, so use the clean cover
art, not a screenshot of an already-stickered sleeve.
